# Loodsman-API

Сервис для выгрузки данных из ЛОЦМАН через REST API. Представляет собой программный аналог спецификации Компас-3D в формате JSON, открывающий новые возможности для интеграции и автоматизации.

## Возможности

- Подключение к ЛОЦМАН через COM-интерфейс
- Построение дерева состава изделия (JSON)
- Выгрузка отчётов в XLSX (4 столбца: наименование детали, количество, обозначение детали, обозначение материала)
- Выгрузка отчёта для КО (5 столбцов, фильтрация стандартных изделий)
- Работа как Windows Service
- Swagger-документация (`/docs`) и ReDoc (`/redoc`)

## Возможности использования

### 1. Автоматизация конструкторской документации
- Выгрузка спецификаций в машиночитаемом формате
- Автоматическое формирование ведомостей материалов
- Контроль комплектности изделий

### 2. Интеграция с корпоративными системами
- **1С:ERP** — передача спецификаций для планирования производства
- **SAP** — импорт номенклатуры и материальных нормативов
- Системы документооборота — автоматическое извлечение атрибутов

### 3. Локализация и перевод документации
- Экспорт наименований и обозначений в JSON
- Удобная подготовка текстов для перевода на иностранные языки
- Поддержка многоязычных спецификаций

### 4. Аналитика и отчетность
- Построение древовидных структур изделий
- Расчет суммарной массы и материалоемкости
- Выявление незакрытых позиций и ошибок в спецификациях

### 5. Разработка внешних приложений
- Создание веб-интерфейсов для просмотра состава изделий
- Интеграция с системами складского учета

## Требования

- Windows (требуется COM + pywin32)
- Установленный ЛОЦМАН с COM-доступом
- Python 3.8+
- Зависимости из `requirements.txt`

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

### Режим разработки

```bash
python run_service.py
```

Сервис будет доступен по адресу: http://localhost:8000

### Как Windows Service

Установка (от имени администратора):

```bash
python install_service.py install
python install_service.py start
```

Удаление:

```bash
python uninstall_service.py
```

Управление:

```bash
python install_service.py install   # установка
python install_service.py start     # запуск
python install_service.py stop      # остановка
python install_service.py remove    # удаление
```

## API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Информация о сервисе |
| GET | `/health` | Проверка работоспособности |
| POST | `/build_json` | Построение дерева изделия (JSON) |
| POST | `/build_report` | Отчёт XLSX (4 столбца) |
| POST | `/build_report_for_ko` | Отчёт XLSX для КО (5 столбцов, фильтрация стандартных изделий) |

## Параметры запроса (`/build_json`, `/build_report`, `/build_report_for_ko`)

```json
{
  "start_id": 12345,
  "max_depth": 15,
  "db_name": "SATOMS"
}
```

- `start_id` — ID начального объекта (изделия или проекта)
- `max_depth` — максимальная глубина рекурсии (1–30, по умолчанию 15)
- `db_name` — имя базы данных ЛОЦМАН (по умолчанию "SATOMS")

## Примеры

```bash
curl -X POST http://localhost:8000/build_json \
  -H "Content-Type: application/json" \
  -d '{"start_id": 12345, "max_depth": 10}'
```
